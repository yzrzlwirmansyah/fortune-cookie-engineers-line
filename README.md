An entry for the [Fortune Cookie Funnies for Engineers](https://make.fun/c/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a) competition on [make.fun](https://make.fun).

`main.py` (Python 3.13 stdlib only) writes one fortune-cookie line for a
software engineer to `/output/entry.txt`:

> You will delete a useless line of code and learn which customer was living in it.

A classic fortune-cookie prophecy with an engineer-specific twist: the
"useless" line of dead code turns out to have a customer living in it.
